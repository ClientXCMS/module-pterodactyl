# Pterodactyl

![Thumbnail](https://api-nextgen.clientxcms.com/assets/a440777f-2231-4f8c-ac27-eeef9c0ac782)

Automatisez entièrement la gestion de vos instances sur Pterodactyl avec l'intégration native pour ClientXCMS. Ce module tout-en-un synchronise votre panneau, attribue dynamiquement les ressources et livre instantanément les serveurs commandés.

Pour installer ce module veuillez vous référez à la documentation.

### Compatibilité

- Pterodactyl 1.x et 2.0 : le module détecte seul la version de chaque panel, rien à configurer. Vérifié sur 1.14.1 et 2.0.0-beta.2.
- Les clés d'API, produits et services existants restent valables après la mise à jour d'un panel en 2.0.
- Après cette mise à jour, le module bascule de lui-même dès la première opération qui touche un egg, sans vider de cache.
- **Mettez à jour ce module avant le panel** : une version antérieure à 1.5.0 ne liste plus aucun egg sur un panel 2.0 et y annonce des suspensions réussies qui n'ont pas eu lieu.

## Pterodactyl

Fully automate the management of your Pterodactyl instances with native integration for ClientXCMS. This all-in-one module synchronizes your panel, dynamically allocates resources, and instantly delivers ordered servers.

To install this module, please refer to the documentation.

### Compatibility

- Pterodactyl 1.x and 2.0: the module detects the version of each panel on its own, nothing to configure. Checked on 1.14.1 and 2.0.0-beta.2.
- Existing API keys, products and services keep working after a panel is upgraded to 2.0.
- After that upgrade, the module switches on its own at the first operation that involves an egg, with no cache to clear.
- **Upgrade this module before the panel**: a version older than 1.5.0 lists no egg at all on a 2.0 panel and reports suspensions that did not happen.
